03 / METHODOLOGY

계산 과정을 공개합니다

01

정렬 · 정제

날짜와 종가의 결측·비양수 값을 제거하고 날짜별 마지막 값을 남깁니다. 수정주가 여부는 입력 데이터의 출처에 따릅니다.

02

로그 수익률

rₜ = ln(Sₜ / Sₜ₋₁). 연속 복리 수익률로 일일 가격 변화를 표현합니다.

03

과거 변동성

σ̂ₜ₋₁ = std(rₜ₋w … rₜ₋₁). 당일 수익률이 분모에 들어가지 않도록 한 칸 이동합니다.

04

탐지 · 방향

qₜ = |rₜ| / σ̂ₜ₋₁. qₜ ≥ k이면 감지하고, rₜ의 부호로 급등과 급락을 나눕니다.

연구 포스터의 공통 선택값은 w = 20, k = 3.70입니다. 보조 기준 모드는 이후 Streamlit 시안의 실험적 시각화 옵션이며 포스터 검증 수치와 직접 비교할 수 없습니다.

04 / RESEARCH CONTEXT

탐지에서 모형 구상까지

SDI–SVJ 개념

충격 지수 qₜ에 반응하는 점프 강도 λₜ = λ₀ exp(γq qₜ)를 제안합니다. 확률변동성과 점프를 함께 다루는 연구 모형의 일부입니다.

이 대시보드는 임계값 탐지 구현입니다. λ₀, γq와 확률변동성 과정은 이 페이지에서 추정하지 않습니다.

포스터의 합성 데이터 검증

여러 변동성·점프 빈도·점프 크기 시나리오에서 공통 파라미터를 탐색했습니다. 포스터에 보고된 F1은 |jump| ≥ 0.03 기준 0.783, ≥ 0.05 기준 0.759입니다.

이는 포스터의 시뮬레이션 결과이며 업로드한 시장 데이터의 성능 또는 미래 예측 정확도가 아닙니다.

연구 발표 → 시각화 시안 실험 → 웹 포트폴리오. 데이터 처리, 수식, 판단 기준을 한 흐름으로 확인할 수 있도록 정리했습니다.
